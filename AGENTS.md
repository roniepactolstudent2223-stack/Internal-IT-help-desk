# Laravel 13 + Vue 3

Keep changes focused. Do not add unnecessary code or interventions beyond the requested task.

## Frontend

- Vue 3 is mounted from `resources/js/app.js`.
- The root Vue component is `resources/js/App.vue`.
- The Blade entry view is `resources/views/welcome.blade.php` and must provide an element with `id="app"`.
- Vite is configured in `vite.config.js` with the Vue plugin.
- Run `npm run dev` during development and `npm run build` to verify a production build.
